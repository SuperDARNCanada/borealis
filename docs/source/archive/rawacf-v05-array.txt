| | **beam_azms**                   | | A list of the beam azimuths for each beam |

| |                                 | | max_num_beams. The num_beams field should |

| |                                 | | ‘max_num_beams’, 'num_ranges', 'num_lags' |
+-----------------------------------+---------------------------------------------+
| | **data_normalization_factor**   | | Scale of all the filters used,            |
